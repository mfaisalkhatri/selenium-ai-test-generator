# Parabank Registration Test

## Requirements
1. ChromeDriver must be in the system PATH
2. TestNG library must be included in the project

## How to Run
1. Open terminal/command prompt
2. Navigate to the project directory
3. Execute the following command:
   ```
   mvn test
   ```
4. Alternatively, run the testng.xml file using TestNG IDE plugin

## Notes
- The test will automatically open a Chrome browser and close it after execution
- All assertions are performed using TestNG's built-in verification framework
